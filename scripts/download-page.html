⚠ Google Play Protect may block this app

Android's Play Protect may warn you, or block the install, because BeamOps isn't on the Play Store and asks for sensitive permissions. This is expected for a staff app and doesn't mean something is wrong. These are the permissions it asks for, and why:

  • Call log and phone status: to show who is calling (caller ID) and to pick a number from recent calls.
  • Show over other apps: so the caller ID pop-up can appear on top of an incoming call.
  • Location: to pin a customer's position on the map.
  • Install updates: so the app can update itself.
  • Run in the background (battery): so alerts arrive on time.
  • Notifications: to alert you about outages, payments and jobs.

BeamOps can't place calls by itself and doesn't read your text messages or contacts.

If Play Protect blocks it: tap More details, then Install anyway. If there is no Install anyway option, ask us before changing any Play Protect setting.

How to install

  1. Tap Download and open the file when it finishes.
  2. If Android says it can't install from this source, tap Settings and turn on Allow from this source, then go back.
  3. If Play Protect shows a warning, tap More details then Install anyway. This is normal for an app that isn't on the Play Store.
  4. Open BeamOps, sign in with your Beam staff account and follow the setup steps.

Already installed? How updates work

  1. BeamOps checks for a new version each time you open it and sign in. If one is out, an Update available pop-up appears. It lists what's new since your version.
  2. Tap Update now. The app downloads the update and checks it is intact. This can take a minute on mobile data.
  3. Tap Install, then confirm in Android's own screen. The first time, Android asks you to allow BeamOps to install updates. Turn on Allow from this source and come back.
  4. Tap Later to skip for now. It asks again the next time you open the app.

Want to check now? Open BeamOps, go to Settings and tap App version. Your data and sign-in are kept when you update.
